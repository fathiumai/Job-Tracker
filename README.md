# JobTrack – Job Application Tracker

A full-stack web application designed to help job seekers organize, manage, and track their job applications in one place.

## Features

- **Dashboard:** View application statistics and recent applications.
- **Application Management:** Add, edit, view, and delete job applications.
- **Search and Filtering:** Find applications by keyword and status.
- **Sorting and Pagination:** Organize and browse application records easily.
- **Charts and Analytics:** Visualize job application statistics.
- **Status Tracking:** Track the progress of each job application.
- **Dark and Light Mode:** Switch between different interface themes.

## Getting Started

### Prerequisites
- Java
- Node.js and npm
- PostgreSQL
- Git

### 1. Clone the repository

```bash
git clone https://github.com/fathiumai/Job-Tracker.git
cd Job-Tracker
```

### 2. Start the backend

Open a terminal in the backend folder:

```bash
cd backend
```

Run the application using the Maven wrapper, if available:

```cmd
mvnw.cmd spring-boot:run
```

Ensure PostgreSQL is running and your database settings and environment variables are configured correctly.

### 3. Start the frontend

Open a second terminal:

```bash
cd frontend
npm install
npm run dev
```

Open the local URL displayed in the terminal.
